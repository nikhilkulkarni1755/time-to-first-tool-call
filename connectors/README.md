# Local connector duplicates

Tool definitions only (no servers). Each file is `{connector, source, tools:[{name, description, input_schema}]}`, with `input_schema` in Anthropic Messages API tool format. The harness exposes a tool to the model as `mcp__<connector>__<tool>`, because two connectors share tool names (`list_issues`).

| File | Tools | Provenance | Fidelity |
|---|---|---|---|
| `github.json` | 20 | Generated by parsing the official `github/github-mcp-server` README tool reference (read 2026-10-16) | High: names, descriptions, parameters, required flags and types come from the README. Nested `object[]` item shapes are not modelled (the README gives none). |
| `slack.json` | 17 | Live `tools/list` of the Slack MCP server connected in this session, cross-checked with docs.slack.dev | Verbatim, except canvas create/update (omitted: very long, not "obvious" calls) |
| `notion.json` | 15 | Live `tools/list` of the Notion MCP server connected in this session, cross-checked with developers.notion.com | Near-verbatim. Date `pattern` regexes dropped and a few tagged unions flattened. Omitted: query-data-sources, query-multiple-data-sources, update-data-source, create-view, update-view (huge schemas) and niche file/skill tools. |
| `linear.json` | 20 | Tool names and descriptions from the official Linear MCP tool list (Speakeasy catalog, Nomic docs); `save_issue` parameters from a public schema listing | **Medium.** All parameters except `save_issue` are reconstructed from the descriptions. Linear's real `tools/list` needs OAuth at `https://mcp.linear.app/mcp`. |
| `cloudflare.json` | 20 | **Hand-built** from the Cloudflare REST API reference | **Low as a duplicate.** Cloudflare's current official MCP server exposes only 3 tools (`search`, `execute`, `docs`, Code Mode); the deprecated product servers have no zone, DNS or cache tools. These 20 are a plausible native typed server, not a copy of one. |

Total: 92 tools, roughly 31k tokens by a characters-divided-by-4 estimate (replace with the real count from the token-counting endpoint).

## Why Cloudflare is different

The brief was to duplicate each connector from its documentation, up to 20 obvious tools. For Cloudflare the documented server is Code Mode, which would make the connector two or three tools and remove the "large tool surface" the benchmark depends on. The hand-built version keeps the realistic shape (a zone/DNS/cache/Workers/KV/R2/D1 surface) but is not what Cloudflare ships. Treat Cloudflare results as "a typed 20-tool Cloudflare-like connector", and say so in any write-up.
